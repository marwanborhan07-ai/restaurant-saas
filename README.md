# Restaurant Growth OS

Phase 1 foundation for a multi-tenant restaurant customer retention SaaS.

## Run
1. Copy `.env.example` to `.env.local`
2. Add Supabase credentials later
3. `npm install`
4. `npm run dev`

## Current Phase
- Next.js + TypeScript
- Tailwind CSS
- Public landing page
- Login/signup placeholders
- SaaS dashboard shell
- Customers, Orders, Segments, Settings placeholders
- Supabase browser client prepared

## Next Phase
Supabase project, database schema, RLS, authentication, restaurant onboarding, and 14-day trial.
